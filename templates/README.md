# Empty artifact templates

These are preparation templates, not completed product decisions, tests, designs or evidence. The dispatched team creates the actual content after receiving the requirements. Copy only a needed template into the assigned artifact path and replace blank fields with observed or authored facts. A blank template is never proof of a gate.

Every completed record must name an exact full commit where applicable, a UTC timestamp, its author's verified literal handle, room event references and absolute artifact paths. Keep failure evidence. Use NOT_TESTED or UNAVAILABLE when measurement or verification did not occur; never fill a successful example into a real record.

The requirements map is intentionally empty. No behavior checks, routes, domain entities, design choices or implementation are seeded here.
